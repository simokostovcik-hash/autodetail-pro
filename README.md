# AutoDetail Pro

A responsive, fictional car detailing studio landing page built with plain HTML, CSS and JavaScript. This is a **portfolio demonstration**, not a real business.

## Features
- Responsive layout with a mobile navigation menu
- Keyboard-friendly navigation and reduced-motion support
- Six sample services and three fictional pricing packages
- Client-side demo contact form (no submission, no storage)
- Inline SVG car illustration and SVG favicon; no external image dependencies

## Run locally
Open `index.html` in your browser. No build tools or installation required.

## Deploy with GitHub Pages
1. Push all project files to the root of your GitHub repository.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for GitHub to provide the public website URL.

## Notes
The contact form is intentionally non-functional as a messaging system. To build a real client website, integrate a secure contact service and replace demo content with verified business information.
